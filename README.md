# StyLens — Image Consultant Assistant

**StyLens** is a hackathon concept for a human-centered AI assistant that supports personalized styling, wardrobe planning, capsule wardrobe creation, and shopping decisions.

## Project Vision

StyLens combines multimodal AI with a professional image-consulting knowledge base covering:

- Face shape
- Body shape and proportions
- 12-season color theory
- Seven universal styles and personal style combinations
- Garment fit, color, contrast, patterns, silhouettes, and accessories
- Outfit ideas, wardrobe planning, and shopping guidance

## Human-in-the-Loop Design

The system provides structured observations, measurable criteria, confidence indicators, and personalized ideas. Human professionals validate the results, apply empathy, consider the client's emotions and life goals, contribute creativity and contextual understanding, and make the final recommendation.


## Technical Direction

The first functional version will:

- Use a human-in-the-loop, knowledge-based architecture
- Evaluate open-weight multimodal models
- Produce structured and explainable outputs
- Measure accuracy, reliability, privacy, latency, licensing, and hardware requirements
- Explore cloud, mobile, local, edge, and hybrid deployment options

## Project Status

This repository currently documents the initial Microsoft Global Hackathon concept. It will be updated as the prototype and deployment progress.
